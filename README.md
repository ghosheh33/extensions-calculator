# Smart Calculator | الآلة الحاسبة الذكية 🧮

إضافة احترافية لمتصفح جوجل كروم تجمع بين البساطة والقوة، مصممة لتكون رفيقك الدائم في العمل والدراسة. توفر تجربة حسابية سلسة مع ميزات متقدمة لا تتوفر في الحاسبات التقليدية.

## 🚀 المميزات الرئيسية

- **وضعية الحاسبة المزدوجة:** تدعم الوضع القياسي والوضع العلمي (sin, cos, log, الجذور، والأسس).
- **محول وحدات متكامل:** تحويل فوري لوحدات الطول، الوزن، وحجم البيانات الرقمية.
- **حساب النصوص المظللة:** الميزة الأذكى؛ ظلل أي معادلة في أي موقع ويب واحسبها عبر قائمة النقر بزر الماوس الأيمن لتظهر النتيجة في نافذة عائمة.
- **تخصيص كامل (Theming):** 3 قوالب تصميمية (فاتح، داكن، رمادي) مع إمكانية اختيار لون مخصص للأزرار.
- **سجل العمليات (History):** حفظ آخر 20 عملية حسابية مع إمكانية استعادتها بضغطة زر.
- **نسخ سريع:** انقر على شاشة النتائج لنسخ الرقم فوراً إلى الحافظة.
- **صفحة ترحيبية:** واجهة تعليمية تفتح تلقائياً عند تثبيت الإضافة لأول مرة.

## 🛠️ التثبيت (للمطورين)

1. قم بتحميل ملفات المشروع أو عمل `Clone` للمستودع.
2. افتح متصفح جوجل كروم واذهب إلى الرابط `chrome://extensions/`.
3. قم بتفعيل **وضع المطور (Developer mode)** من الزاوية العلوية.
4. اضغط على **تحميل حزمة غير محزمة (Load unpacked)**.
5. اختر مجلد المشروع الذي يحتوي على ملف `manifest.json`.

## 📁 هيكلية الملفات

- `manifest.json`: إعدادات الإضافة وصلاحياتها.
- `popup.html/css/js`: واجهة المستخدم الرئيسية والمنطق البرمجي للحاسبة والمحول.
- `background.js`: معالج القوائم السياقية والعمليات في الخلفية.
- `content.js`: المسؤول عن إظهار النافذة العائمة فوق النصوص في صفحات الويب.
- `welcome.html`: صفحة الترحيب والتعليمات.
- `Icons/`: مجلد يحتوي على أيقونات الإضافة بأحجامها المختلفة.
